# Managing your website

A short guide for Asanka. No technical knowledge needed.

## Signing in

1. Go to **yoursite.com/admin**
2. Username `admin`, and the password you were given.
3. Change your password any time — ask your developer to run the password change, or use the API
   endpoint set up for it.

## Changing a picture

Every picture on the site is changed the same way:

1. Open the section it belongs to (see the table below).
2. Click the item, then **Upload image**.
3. Choose the photo from your computer. It appears in the small preview straight away.
4. Click **Save changes**.
5. Refresh the public site — the new photo is live.

| Picture on the site | Where to change it |
|---|---|
| Big homepage slideshow | Site content → Homepage slideshow |
| About page pictures | Site content → About page |
| Green "Ceylon" band on the homepage | Site content → Island section |
| Vehicle photos | Vehicles → open a vehicle |
| Destination photos | Destinations → open a guide |
| Gallery photos | Gallery |
| Guest photos on reviews | Reviews → open a review |

Photos taken on a phone are fine. Landscape (wide) photos look best. Very large files take longer
to load for visitors — under 2 MB per photo is a good target.

## Changing prices

Vehicles → open the vehicle → change **Price per km** and **Price per day** → Save. The tariff
table on the site updates immediately.

## Adding a new destination guide

Destinations → **Add new**. Fill in the title, district, a short summary, and the full text. Leave
a blank line between paragraphs. Tick **Published** to make it visible, and **Feature on the
homepage** if you want it in the top three.

## Reviews

- Reviews left by visitors appear in the Reviews list but are **not** shown on the site until you
  tick **Show on the site**.
- Tick **Feature on the homepage** for the three you want guests to read first.

## Bookings and messages

- **Bookings** — every request from the site, with a reference like `TWA-4F2A9C`. Change the status
  as you handle it so you can see what is still open.
- **Messages** — questions from the contact form. Mark them read once you have replied.

## If something looks wrong

Refresh the page first. If a photo does not appear, check that it saved — reopen the item and look
at the preview. Nothing you do in the admin panel can break the site design.
